무엇에 의존하나

스타일과 스크립트는 코드 안에 들어갑니다. 붙여 넣은 뒤에는 이 사이트가 사라져도 영향을 받지 않습니다. 바깥에서 받아오는 것은 공개 라이브러리 두 개뿐입니다.

StPageFlip지면 넘김. jsDelivr page-flip@2.0.7
PDF.jsPDF 읽기. jsDelivr pdfjs-dist@4.6.82

둘 다 npm 공개 패키지이고, 기관 홈페이지가 이미 같은 CDN 에서 글꼴(Pretendard)을 받아 쓰고 있습니다. PDF 는 방문자의 브라우저가 홈페이지에서 직접 읽습니다.
