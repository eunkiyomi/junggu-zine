제목은 어디에?

뷰어는 지면만 보여 줍니다. 페이지 제목(‘웹진’)은 믹스온이 페이지에 이미 그려 주기 때문에, 뷰어가 또 그리면 제목이 두 번 나옵니다.

코드가 하는 일

붙여 넣는 코드는 PDF 주소만 담고 있습니다. 스타일과 스크립트는 이 저장소의 GitHub Pages 에서 불러오고, PDF 는 방문자의 브라우저가 홈페이지에서 직접 읽어 그립니다. 그래서 코드가 짧고, 새 호로 바꿀 때 PDF 만 갈아 끼우면 됩니다.
