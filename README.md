# 서울시중구재가노인복지기관 — 2025 하반기 소식지 (HTML 에디션)

사회복지법인 한밀 · 서울시중구재가노인복지기관에서 발행한 **2025년 하반기 소식지(통권 제1호, 전 8면)**의
내용을 **이미지 스캔이 아닌 실제 본문 HTML로 옮긴** 웹 에디션입니다.

> 두 가지 버전이 브랜치로 나뉘어 있습니다.
> - `main` — 원본 지면 스캔을 넘겨보는 **이미지 웹진**(리더 + 갤러리 + 라이트박스)
> - `html-edition` — **본문을 HTML로 재구성한 에디션** (현재 브랜치)

## 특징

- 소식지 전체를 **시맨틱 마크업**으로 재구성 — 어떤 화면에서도 본문이 리플로우됩니다.
  - **인사말** 편지, **법인 소개**(설립 목적 / 비전 / 미션) 카드
  - **분기별 주요소식**(2~4분기) — 분기별 색상으로 구분한 뉴스 카드 + 날짜 배지
  - **프로그램 및 주요 서비스**(실버푸드테라피, 함사발, 병원동행, 행정지원)
  - **현황** — 수입·지출을 실제 `<table>`로, 자원봉사자·후원자 명단, 후원 사례
  - **후원 / 자원봉사 안내** — 강조된 후원 계좌 + 발행정보 푸터
- 섹션 내비게이션(스크롤 스파이), 맨 위로 버튼, 각 섹션 → **원본 스캔 링크**
- 외부 의존성 없는 순수 HTML/CSS/JS (폰트만 Google Fonts CDN)

## 구성

```
index.html         # 본문 HTML 에디션
assets/edition.css # 스타일 (기관 홈페이지 톤: 틸 #18ACBB / 오렌지 #FF9C37 / 화이트, Inter)
assets/edition.js  # 스크롤 스파이 + 맨 위로 버튼
zine/001–008.jpg   # 원본 스캔 8면 (표지 + 각 섹션 원본 링크용)
```

## 실행

빌드 과정이 없습니다. 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```
