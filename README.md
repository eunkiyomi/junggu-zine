# 서울시중구재가노인복지기관 — 2025 하반기 소식지 웹진

사회복지법인 한밀 · 서울시중구재가노인복지기관에서 발행한 **2025년 하반기 소식지(통권 제1호, 전 8면)**를
웹에서 보기 편하게 재구성한 정적 웹진입니다.

## 기능

- **지면 보기(Reader)** — 좌우 화살표·키보드(← →)·터치 스와이프로 한 면씩 넘겨보기, 썸네일 바로가기
- **목차(Contents)** — 원문 목차에서 원하는 면으로 바로 이동
- **전체 지면(Gallery)** — 8면 썸네일 그리드
- **확대 보기(Lightbox)** — 전체 화면 확대, 키보드·스와이프 탐색
- 반응형 레이아웃, 외부 의존성 없는 순수 HTML/CSS/JS (폰트만 Google Fonts CDN)

## 구성

```
index.html        # 마크업
assets/style.css  # 스타일 (소식지 팔레트: 골드 + 크림 + 플럼)
assets/app.js     # 리더 / 목차 / 갤러리 / 라이트박스 로직
zine/001–008.jpg  # 소식지 원본 8면 (001 = 표지)
```

## 실행

빌드 과정이 없습니다. 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```
