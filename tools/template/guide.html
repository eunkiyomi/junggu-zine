웹진 설치 안내

서울시중구재가노인복지기관 홈페이지에 ‘웹진’ 메뉴를 추가하는 방법

1. 무엇을 보내드렸나요

소식지 PDF를 책처럼 넘겨 보는 웹 페이지로 만들었습니다. 소식지 내용을 다시 옮겨 적은 것이 아니라 발행하신 PDF를 그대로 화면에 보여 주기 때문에, 인쇄물과 지면이 100% 똑같습니다.

__ZINE_FILE__웹진 파일입니다. 이 파일 하나만 올리면 됩니다. (__ZINE_SIZE__)
웹진-만들기.html다음 호가 나왔을 때 직접 새 웹진을 만드는 도구입니다. (__BUILDER_SIZE__) 자세한 사용법은 5번 항목을 보세요.
웹진-설치안내.html지금 보고 계신 안내문입니다.
OFL.txt웹진에 사용한 글꼴(Pretendard)의 라이선스 전문입니다.
먼저 그냥 열어 보셔도 됩니다

__ZINE_FILE__ 파일을 마우스로 두 번 누르면 브라우저에서 바로 열립니다. 서버에 올리기 전에 어떤 모습인지 확인해 보세요. 인터넷 연결이 없어도 열립니다.

3. 홈페이지에 넣는 방법

기관 홈페이지 메뉴 구조상 커뮤니티 아래 (공지사항 · 포토앨범 · 카드뉴스 · 고충 및 건의 사항 옆)에 웹진을 추가하시는 것이 자연스럽습니다.

준비 — 파일 올리기

  1. 믹스온 관리자로 로그인합니다.
  2. __ZINE_FILE__ 파일을 홈페이지 파일 저장소(파일 업로드)에 올립니다.
  3. 올라간 파일의 주소(URL)를 복사해 둡니다.
    예: https://seouljunggusilver.mixon.io/uploads/.../__ZINE_FILE__

방법 A — 페이지 + HTML 블록 (권장)

믹스온에는 페이지에 직접 코드를 넣을 수 있는 HTML 블록이 있습니다 (믹스온 가이드의 ‘🧩 페이지 블록’ 항목 참고). 이 방법이 가장 깔끔합니다.

  1. 커뮤니티 아래에 웹진 페이지를 새로 만듭니다.
  2. 그 페이지에 HTML 블록을 추가합니다.
  3. 아래 코드를 붙여 넣습니다. 여기에_올린_파일_주소 부분만 위에서 복사해 둔 주소로 바꿔 주세요.
  4. 저장하고 메뉴에 웹진을 노출시킵니다.
<div style="width:100%;max-width:1136px;margin:0 auto;">
  <iframe
    src="여기에_올린_파일_주소?bare=1"
    title="웹진 — __SUBTITLE__"
    loading="lazy" allowfullscreen allow="fullscreen"
    style="display:block;width:100%;height:78vh;min-height:420px;
           max-height:860px;border:0;border-radius:8px;">
  </iframe>
</div>
코드에서 바꿔도 되는 것

?bare=1 — 웹진 파일 안에 들어 있는 제목·기관 정보를 숨기고 뷰어만 보여 줍니다. 홈페이지 페이지에 이미 ‘웹진’ 제목이 있으니 붙이시는 편이 좋습니다. 전체를 다 보이게 하려면 이 부분만 지우면 됩니다.

height:78vh — 높이입니다. 화면 높이의 78%로 자동 조절됩니다. 더 크게 보이려면 숫자를 올리고(예: 85vh), 작게 하려면 내리면 됩니다.

allowfullscreen — 이걸 지우면 전체 화면 버튼이 동작하지 않습니다.

방법 B — 메뉴에서 파일로 바로 연결

HTML 블록을 쓰기 어렵거나 더 간단히 하고 싶으시면, 웹진 메뉴를 링크 메뉴로 만들어 올려 둔 파일 주소로 바로 연결해도 됩니다. 이 경우 ?bare=1 없이 파일 주소만 넣으시면 웹진 파일에 들어 있는 제목·기관 정보까지 함께 나옵니다.

확인 부탁드립니다

아래 두 가지는 관리자 화면에서만 확인할 수 있어 저희가 미리 알 수 없었습니다. 혹시 막혀 있다면 알려 주세요. 다른 방식으로 만들어 드리겠습니다.

  • .html 파일 업로드가 허용되는지 — 보안상 막아 두는 경우가 있습니다.
  • HTML 블록에 <iframe>이 허용되는지 — 일부 편집기는 자동으로 지웁니다.

둘 다 막혀 있다면, 웹진 파일을 다른 곳에 올려 두고 그 주소만 연결하는 방법도 있습니다.

4. 알아 두시면 좋은 점

  • 인터넷 주소가 면마다 남습니다. 3면을 보고 계실 때 주소 끝에 #p3이 붙습니다. 그대로 복사해서 “3면을 보세요”라고 안내할 수 있습니다.
  • 글꼴은 홈페이지와 같은 Pretendard를 씁니다. 홈페이지와 동일하게 CDN에서 받아 쓰되, 혹시 CDN이 막히면 파일 안에 넣어 둔 예비 글꼴로 똑같이 보입니다.
  • 어르신을 고려했습니다. 버튼을 크게 하고, ‘크게 보기’로 글씨를 최대 4배까지 키울 수 있게 했습니다. 키보드 화살표와 화면 낭독기도 지원합니다.
  • 따로 설치할 것이 없습니다. 파일 하나로 끝나며, 나중에 옮기거나 지우기도 쉽습니다.
지금 파일의 화질에 대해

이번 웹진은 전달받은 지면 이미지(가로 722픽셀)를 바탕으로 만들었습니다. 읽는 데는 문제가 없지만, 크게 보기로 많이 확대하면 글씨가 다소 흐릿합니다.

인쇄용 원본 PDF(고해상도)를 주시면 같은 방법으로 다시 만들어 드립니다. 그러면 확대해도 글씨가 또렷합니다.

5. 다음 호로 바꾸기 — 직접 하실 수 있습니다

새 소식지가 나오면 직접 새 웹진을 만드실 수 있습니다. 함께 보내 드린 웹진-만들기.html 을 열고 새 PDF 를 올리기만 하면 됩니다. 프로그램을 설치할 필요가 없고, PDF 는 어디로도 전송되지 않고 담당자분 브라우저 안에서만 처리됩니다.

  1. 웹진-만들기.html 을 마우스로 두 번 눌러 엽니다.
  2. 새 소식지 PDF 를 고르거나 끌어다 놓습니다.
  3. 설명란에 새 호수를 적습니다. (예: 2026 상반기 소식지 · 통권 제2호)
  4. [웹진 파일 만들기] 를 누르고 잠시 기다립니다.
  5. [웹진 파일 내려받기] 로 받은 파일을, 홈페이지에 올라가 있는 기존 웹진 파일과 바꿔치기합니다.
파일 이름을 똑같이 맞춰 주세요

새로 받은 파일의 이름을 기존 파일과 똑같이 (__ZINE_FILE__) 바꾼 뒤 덮어쓰시면, 메뉴나 붙여 넣은 코드를 하나도 고치지 않아도 됩니다.

이 도구는 인터넷 연결이 필요합니다(PDF 를 읽는 프로그램을 잠깐 내려받습니다). 막혀 있거나 잘 안 되시면 PDF 를 보내 주세요. 저희가 만들어 드리겠습니다.
